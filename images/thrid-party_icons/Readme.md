This sub-folder contains images as png format. Some of the symbols used in this project are third-party freeware icons obtained from various sources.

## [1] Symbols from Erik Flowers

The following symbols are used in this project:

    * wi--day-cloudy.png
    * wi--day-sunny.png
    * wi--rain.png
    * wi--raindrops.png
    * wi--thermometer.png

These symbols were created by <b>Erik Flowers</b> and are published under the <i>Open Font License</i> at the following link: https://icon-sets.iconify.design/wi/page-2.html?keyword=weather

The small start-screen icons in `images/thermometer.png`, `images/water-drop.png`, and `images/leaf.png` are cropped and scaled from the existing `images/static_screen1_background.png` artwork. Their one-byte-per-pixel device assets are stored in `src/img/` under the same names with a `.bin` extension. The leaf reuses the original background artwork; the thermometer and drop retain the existing icon attribution above.
